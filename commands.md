⭐ 1. pwd
Description: Shows your current directory.
Example:

Code
pwd
When to use: Anytime you forget where you are in the filesystem.

⭐ 2. ls
Description: Lists files and folders.
Example:

Code
ls -l
When to use: To see what’s inside a directory.

⭐ 3. cd
Description: Change directory.
Example:

Code
cd ~/Linux/practice
When to use: Anytime you want to move somewhere else in the filesystem.

⭐ 4. mkdir
Description: Create a new folder.
Example:

Code
mkdir projects
When to use: When organizing files or creating practice folders.

⭐ 5. touch
Description: Create an empty file.
Example:

Code
touch notes.txt
When to use: When practicing or creating new files quickly.

⭐ 6. mv
Description: Move or rename files.
Example:

Code
mv file.txt archive/
When to use: To organize files or rename them.

⭐ 7. cp
Description: Copy files or folders.
Example:

Code
cp file.txt backup.txt
When to use: When you want a duplicate of a file.

⭐ 8. rm
Description: Delete files or folders.
Example:

Code
rm file.txt
When to use: When cleaning up practice files.

⭐ 9. rm -r
Description: Delete folders and everything inside.
Example:

Code
rm -r old_folder
When to use: When removing entire directories.

⭐ 10. cat
Description: Display file contents.
Example:

Code
cat notes.txt
When to use: To quickly read a file.

⭐ 11. nano
Description: Simple text editor in the terminal.
Example:

Code
nano notes.txt
When to use: When editing files directly in Linux.

⭐ 12. echo
Description: Print text or write text into a file.
Example:

Code
echo "Hello" > hello.txt
When to use: To create quick text files or test output.

⭐ 13. head
Description: Show the first 10 lines of a file.
Example:

Code
head bigfile.txt
When to use: When previewing large files.

⭐ 14. tail
Description: Show the last 10 lines of a file.
Example:

Code
tail log.txt
When to use: When checking logs or recent output.

⭐ 15. grep
Description: Search for text inside files.
Example:

Code
grep "error" log.txt
When to use: When finding specific lines or patterns.

⭐ 16. find
Description: Search for files or folders.
Example:

Code
find . -name "*.txt"
When to use: When locating files anywhere in the system.

⭐ 17. chmod
Description: Change file permissions.
Example:

Code
chmod +x script.sh
When to use: When making scripts executable.

⭐ 18. chown
Description: Change file ownership.
Example:

Code
sudo chown user:user file.txt
When to use: When fixing permission issues.

⭐ 19. sudo
Description: Run commands as administrator.
Example:

Code
sudo apt update
When to use: When installing software or modifying system files.

⭐ 20. apt
Description: Install and update software on Ubuntu.
Example:

Code
sudo apt install python3
When to use: Anytime you need to install packages.
